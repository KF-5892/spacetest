# コスモライナー(仮称) — 宇宙飛行体験アプリ

> **「ブラウザを開いて30秒後、あなたは宇宙船の乗客になる。」**

ディズニーランドの「スターツアーズ」のような、**誰でも・安全に・約5分で宇宙を飛び回れる**没入型ライド体験を、
ブラウザ(Three.js/WebGL)上で実現するプロジェクトです。

## コンセプト

1. **ライドである** — 操縦できなくても楽しい。ガイドに導かれる全自動のシネマティック宇宙遊覧
2. **生きた宇宙である** — 実在の太陽系がベース。惑星は巨大で、星雲は美しく、知識が驚きに変わる
3. **二度と同じ旅はない** — 出発 × 目的地 × 航路イベントの組み合わせで、乗るたびに違うツアーになる

## 技術方針(概要)

- **プラットフォーム**: Webブラウザ(静的配信、インストール不要)
- **3D**: Three.js(WebGL2基盤、WebGPUはプログレッシブ対応)
- **言語/ビルド**: TypeScript + Vite
- **設計原則**: シーン=データ(JSON)、演出=再利用可能なビルディングブロック。シーン追加をコード変更なしで可能に
- **快適性**: コックピット固定参照枠・等速基調・快適性設定を初期設計から組み込み(3D酔い対策は後付け不可)

詳細は [要件定義書 §9](./docs/02_requirements.md#9-技術要件選定方針) を参照。

## 権利について

本プロジェクトは既存IP(スター・ウォーズ/ディズニー等)の名称・キャラクター・音楽・デザインを使用しません。
参考にしているのは公開情報から分析した「体験の構造」のみです。天体テクスチャ等はNASA/JPL等のパブリックドメイン素材を使用予定です。
